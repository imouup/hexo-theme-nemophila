* ✨ 首页Tweet 动态：随时从任何设备向Blog发送首页动态 🥰
* 📐 KaTeX 数学公式渲染
* 🔗 自定义 \<link-ing\> 标签：站内、站外链接卡片
* 🎵 类Apple Music的音乐页面
* ⛩️ Bangumis番组页（需安装[hexo-bilibili-bangumi](https://github.com/HCLonely/hexo-bilibili-bangumi)插件）
* 🔍 全站搜索
* 💻 代码块：类Notion设计
* 💬 [Waline](https://github.com/walinejs/waline) 评论系统
* ♥️ 访问量统计：基于 [Vercount](https://github.com/EvanNotFound/vercount)
* 📱 全响应式设计
* 🔠 字体CDN国内 (font.im) 国外 (Google Fonts) 自动切换
* 很可爱的小八千代
* 很可爱的isekaijoucho


<br>

# 开始使用

进入Hexo的 `themes` 目录
```
git clone https://github.com/imouup/hexo-theme-nemophila.git
```

修改hexo配置文件的 `theme` 字段为 `hexo-theme-nemophila`
